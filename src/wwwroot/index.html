Common Lisp in a browser tab

dotcl — a Common Lisp implementation on .NET — compiled to WebAssembly. Not a subset: 21932 of the 21937 tests in the ANSI test suite pass. Nothing is installed and nothing is sent anywhere; the Lisp runs in the tab.

The playground →

Chapters you can edit and run. Errors arrive carrying restarts, and any block can be shared as a link.

Drawing →

A canvas filled from Common Lisp, with the source sitting in the page as a <script type="text/common-lisp"> the browser leaves alone.

A REPL →

dotcl's own REPL on a terminal in the page: line editing, TAB completion, the debugger, and Ctrl+C to interrupt.
Source — the whole site is built from the published DotCL.Runtime package, with no binary committed to it.
